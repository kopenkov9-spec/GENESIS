## Кои моменти да снимаш

Най-ценната двойка кадри е първото селище и завръщането на същото място след звездния полет. Остави името на планетата, епохата и координатите в кадър. За останалото снимай това, което ти е направило впечатление. Следните имена са предложения за подбор от една кампания.

The opening settlement and the homecoming make a matched pair. Keep the planet name, epoch and coordinates visible and use the same map or field view for both. Choose the other frames from the moments that stood out in your own run.

| Предложено име / Suggested name | Момент | What to show |
| --- | --- | --- |
| `01-first-cell.png` | Първото хранене | A cell approaching a nutrient bloom |
| `02-dry-shore.png` | Излизане на сушата | The evolved organism at the shore or its anatomy with the air sac visible |
| `03-settlement.png` | Преди полета | The first settlement with the field coordinates in view |
| `04-reactor.png` | Магия и технология | The built reactor or the experiment that made it possible |
| `05-foreign-orbit.png` | Първи контакт | A foreign system with the ship and the civilization's name |
| `06-created-world.png` | Нов свят | The planet list after creating a world, or a seeded ecosystem on its surface |
| `07-homecoming.png` | След полета | The same shore and settlement as frame 03, in a later epoch |

## За еднакъв ракурс · Matching the two views

1. При първото селище запиши seed-а, името на планетата и координатите под терена. Натисни **P**, за да спреш времето за кадъра. Натисни пак, за да продължиш.
2. След космическата епоха използвай **Атлас → Галактика → Родна звезда → Скок**, после **Кацни** до планетата **Дом**. Върни се на старите координати. Запази същия размер на прозореца и същия панел.
3. За надписа запиши какво действително се е променило. Селището може да е същото, докато епохата, сградите наоколо или историята на вида са различни.

Note the seed, planet, coordinates and panel used for the first shot. Press **P** to pause and again to resume. After spaceflight, select **Atlas → Galaxy → Home star → Jump**, land on the planet marked **Home**, and frame the same site at the same window size. Describe what the later frame actually shows.

## Добавяне на избраните снимки · Adding selected images

Сложи подбраните файлове в тази папка. В главните `README.md` и `README.en.md` добави заглавие и снимките между коментарите `gallery:start` и `gallery:end`. Шаблоните долу са за корена на хранилището. Замени описанията с видимото в действителния кадър.

Place the selected pictures in this folder. Add the gallery heading and images between the two gallery comments in each root README. The examples below are relative to the repository root. Use the actual filename, extension and letter case, and write alt text that describes the selected frame.

```markdown
## Галерия

![Първото крайбрежно селище на родната планета](docs/gallery/03-settlement.png)

![Същото селище след завръщането на кораба](docs/gallery/07-homecoming.png)
```
